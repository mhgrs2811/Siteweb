minimum pour les visuels pleine largeur), puis renseigner les chemins dans :
- src/data/siteConfig.ts   → logo (logo-gorbuz.svg ou .png)
- src/data/menuData.ts     → image des familles et des produits
- src/data/galleryData.ts  → galerie (src, width, height, alt)
