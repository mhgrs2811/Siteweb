À COMPLÉTER APRÈS LA V1 — SNACK GORBUZ

Chaque ligne indique où la donnée s'intègre dans le code.

======================================================================
[ ] Logo officiel (SVG vectoriel ou PNG transparent, 2 000 px de large minimum)

    → remplace automatiquement le wordmark typographique provisoire partout.
[ ] Charte existante éventuelle (couleurs, typographies, règles d'usage)
    → à comparer avec src/app/globals.css (tokens --c-*) et validation DA.

    → siteConfig.baseline

    → src/data/copy.ts (tous les textes sont centralisés)

2. INFORMATIONS PRATIQUES
======================================================================
[ ] Adresse complète (rue, numéro, code postal, commune)
    → siteConfig.address { street, postalCode, city, country }
[ ] Lien Google Maps / itinéraire officiel
    → siteConfig.address.mapsUrl (active le bouton « Itinéraire » header/footer/CTA)
[ ] URL d'embed de la carte (Google Maps « Intégrer une carte » ou OpenStreetMap)
    → siteConfig.address.mapEmbedUrl (active la carte interactive sur /contact)
[ ] Numéro de téléphone (format affiché souhaité)
    → siteConfig.phone (active les liens tel:)
[ ] Adresse email de contact
    → siteConfig.email (active les liens mailto:)
[ ] Horaires d'ouverture par jour, créneaux multiples et jours de fermeture
    → siteConfig.openingHours [{ day, slots: [{ from, to }], note? }]
[ ] Mention horaires (jours fériés, service continu, fermeture annuelle…)
    → siteConfig.openingNote
[ ] Canal de commande : téléphone, plateforme (Takeaway, Uber Eats…), click & collect, sur place uniquement
    → siteConfig.orderUrl (si lien) ; sinon les CTA restent « Voir la carte »
[ ] Modalités de retrait / livraison, si elles existent
    → copy.contact.noteText + éventuel bloc dédié

3. LA CARTE
======================================================================
[ ] Liste complète des familles (durums, kumpirs, mitraillettes confirmées ; autres ?)
    → src/data/menuData.ts → families[] (ajouter un objet Family par famille)
[ ] Pour chaque produit : nom exact, description courte, prix TTC en euros
    → families[].products[] { id, name, description, price }
[ ] Formats / tailles et leurs prix (ex. normal / grand)
    → products[].variants [{ label, price }]
[ ] Suppléments et options avec prix (ou « inclus »)
    → products[].options [{ label, price }]
[ ] Allergènes CONFIRMÉS par produit (liste UE 14 allergènes)
    → products[].allergens (ne rien renseigner tant que ce n'est pas validé)
[ ] Produits à mettre en avant : signature, nouveauté, populaire
    → products[].badge ; vedette de l'accueil : menuData.featuredProduct
[ ] Carte PDF officielle si elle existe
    → public/media/carte-gorbuz.pdf + siteConfig.menuPdfUrl
[ ] Gestion des disponibilités (produit indisponible) : souhaitée ou non ?
    → products[].available
