# StudioTwice

Site vitrine de StudioTwice (Next.js App Router, TypeScript, Tailwind v4, GSAP, Lenis, Three.js).

- Les règles de design du dépôt sont dans `../CLAUDE.md`.
- Les textes du hero sont dans `src/content/hero.ts`, les couleurs dans `src/lib/tokens.ts` et `src/app/globals.css`.
- Les polices sont auto-hébergées dans `src/fonts` (Archivo variable, Onest variable).
